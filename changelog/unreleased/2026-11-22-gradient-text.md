- **`El::text_gradient(angle, stops)` fills text glyphs with a linear gradient across the element's box like CSS `background-clip: text`.** Uses the same CSS radian convention and up to 16 stops as `El::linear_gradient`, works in both the uber shader (including subpixel LCD text) and `cpu_boot` with no extra render passes, mirrors in RTL, and lets explicit span/selection colours and colour emoji keep their own ink.
